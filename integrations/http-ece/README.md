# http_ece 许可证补件

锁定的 `http_ece@1.2.0` 是 Web Push 载荷加密依赖。其 npm 发布包声明 MIT 许可，但未包含许可证正文。本目录保留该版本 npm 元数据 `gitHead` 对应上游提交的许可证全文，仅将末尾多个空行规范为一个换行；装配时只对这个固定版本和完整性值补入，不修改安装目录或放宽其他依赖的许可检查。

- 上游：[martinthomson/encrypted-content-encoding](https://github.com/martinthomson/encrypted-content-encoding)
- 版本提交：`0562510a30819f52424724a6fd5504becacd98a1`
- 原文：[LICENSE](https://github.com/martinthomson/encrypted-content-encoding/blob/0562510a30819f52424724a6fd5504becacd98a1/LICENSE)
- npm 元数据：[http_ece 1.2.0](https://registry.npmjs.org/http_ece/1.2.0)

补件哈希由发行装配脚本固定；许可证随装配清单分发到对应依赖目录。
