# Coproxy

Coproxy 面向 Linux 网关，提供可通过浏览器管理的局域网代理、DNS 与分流能力。终端通过接入路由器统一使用服务，无需逐台安装代理客户端；软件不绑定个人设备或当前调试网络。

当前处于方案与选型阶段，尚无运行实现、发行包或已通过的设备联调。首选评估 Mihomo 与 MetaCubeXD Server／Agent 的组合，并用 v2rayA 对照完整管理与接管能力；最终组件和版本在验证后冻结，不将候选写成已交付功能。
